A free daily Panchang with clearer location controls, offline worldwide city search and more control over what appears in your calendar.

- Equal-height location, date, time and action controls, including Safari.
- Offline search for 34,145 city centres, saved places and larger text settings.
- Monthly calendar export with category filters and advance reminder choices.
- A summary-sharing option without coordinates; coordinate-bearing links are an explicit choice and use URL fragments.
- Minimal creator credit, plain-language explanations, local mismatch reports, public help and privacy pages.
- Stricter import validation, desktop network/permission/navigation restrictions, hardened Electron packaging, native backup exclusions and restricted export storage.
- Independent calculation/reference tests plus browser, accessibility and platform build checks. Read the source research and accuracy documents for measured bounds and remaining gaps.

## Installation status

The web app is at https://panchang.eksaar.com/ and can be installed through supported browsers. GitHub Pages remains an alternate at https://gopalasubramanium.github.io/panchang_clock/.

These CI artifacts are development beta packages: desktop files prefixed UNSIGNED are not platform-trusted releases; Android DEBUG is a test APK, the AAB is unsigned, and iOS SIMULATOR ONLY is not installable on an iPhone. Build provenance and checksums identify files and source; they do not substitute for platform signing, notarization or store review. Any separately supplied Developer ID-signed macOS package must state its notarization status explicitly.

Festival and fasting rules remain previews. Complete regional calendars, Smarta/Vaishnava/Parana rules, full explanatory translations, home-screen widgets and watch apps are not yet available. No claim of universal accuracy, complete security or guaranteed reminder delivery is made.
